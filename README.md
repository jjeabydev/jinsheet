# JinSheet

[Install from the VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=jjeabydev.jinsheet) · [Report an issue](https://github.com/jjeabydev/jinsheet/issues)

JinSheet lets you work with spreadsheets and preview Office and PDF files in VS Code. Spreadsheet data stays on your computer; document contents are not uploaded.

## Features

- Edit CSV and TSV files, and supported XLSX workbooks. Sort, filter, search, and paste cell ranges.
- Preview PDF pages, Word documents, and PowerPoint slides in the editor.
- Zoom and fit document pages to the editor width or height.

## File support

| Format | View | Edit and save |
| --- | --- | --- |
| CSV, TSV | Yes | Yes |
| XLSX | Yes | For supported workbooks |
| XLSM | Yes | No |
| PDF, DOCX, DOCM, PPTX, PPTM | Yes | No |
| XLS, ODS, DOC, PPT | No | No |

XLSX editing is limited to workbooks JinSheet can safely preserve. Unsupported workbooks open read-only; formulas are shown but not recalculated. Word and PowerPoint previews may differ from Microsoft Office. Complex animations, transitions, and media playback are not supported.

## 한국어

JinSheet는 VS Code에서 CSV·TSV와 지원되는 XLSX 파일을 편집하고, PDF·Word·PowerPoint 파일을 미리 보는 확장입니다. 파일 내용은 PC에 남으며 외부로 전송하지 않습니다.

- CSV·TSV 및 지원되는 XLSX 편집: 셀 수정, 정렬, 필터, 검색, 범위 붙여넣기
- PDF 페이지, Word 문서, PowerPoint 슬라이드 미리보기
- 문서 확대·축소, 너비 또는 높이에 맞춤

XLSX는 안전하게 보존할 수 있는 구조만 수정·저장할 수 있습니다. 지원 범위 밖의 파일은 읽기 전용으로 열리며 수식은 다시 계산하지 않습니다. Word·PowerPoint 미리보기는 Microsoft Office와 다를 수 있고 복잡한 애니메이션·전환·미디어 재생은 지원하지 않습니다.
