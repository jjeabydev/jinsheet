# JinSheet

[Install from the VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=jjeabydev.jinsheet) · [Report an issue](https://github.com/jjeabydev/jinsheet/issues)

JinSheet lets you edit spreadsheets and preview Office and PDF files in VS Code. Files stay on your computer.

## Features

- Edit CSV, TSV, and supported XLSX workbooks. Sort rows, find cell contents, and paste cell ranges.
- Preview PDF pages, Word documents, and PowerPoint slides.
- Zoom pages and slides, or fit them to the viewer width or height.

## Sorting and search

Sorting always keeps the first row as the header; choosing a different header row is not supported yet. Click a column heading to sort the remaining rows; click again to reverse the order. Use **Clear sort** to restore the original row order. Search finds text in the current sheet.

## File support

| Format | View | Edit and save |
| --- | --- | --- |
| CSV, TSV | Yes | Yes |
| XLSX | Yes | Supported workbooks |
| XLSM | Yes | No |
| PDF, DOCX, DOCM, PPTX, PPTM | Yes | No |
| XLS, ODS, DOC, PPT | No | No |

Unsupported XLSX workbooks open read-only. Formulas are shown but not recalculated. Word and PowerPoint previews may differ from Microsoft Office; complex animations, transitions, and media playback are not supported.

## 한국어

JinSheet는 VS Code에서 스프레드시트를 편집하고 Office·PDF 파일을 미리 보는 확장입니다. 파일은 PC에 남습니다.

- CSV·TSV와 지원되는 XLSX 편집: 행 정렬, 셀 검색, 범위 붙여넣기
- PDF 페이지, Word 문서, PowerPoint 슬라이드 미리보기
- 페이지·슬라이드 확대/축소와 뷰어 너비·높이에 맞춤

정렬할 때 첫 행은 머리글로 고정됩니다. 다른 행을 머리글로 지정하는 기능은 아직 지원하지 않습니다. 열 머리글을 클릭해 나머지 행을 정렬하고, 다시 클릭하면 순서를 바꿉니다. **정렬 해제**를 누르면 원래 순서로 돌아갑니다. 검색은 현재 시트의 텍스트를 찾습니다.

지원 범위를 벗어난 XLSX는 읽기 전용으로 열립니다. 수식은 표시하지만 다시 계산하지 않습니다. Word·PowerPoint 화면은 Microsoft Office와 다를 수 있으며 복잡한 애니메이션·전환·미디어 재생은 지원하지 않습니다.
