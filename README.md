# JinSheet — Excel & CSV Editor, Office Text Preview

JinSheet는 CSV·TSV와 제한된 XLSX 통합문서를 VS Code에서 로컬로 확인·수정하고, Word·PowerPoint 문서의 텍스트를 읽기 전용으로 미리 보는 확장입니다. 데이터 보존을 우선하며, 지원 여부를 판정하지 못하는 XLSX는 수정 저장을 막고 이유를 표시합니다. XLSX 수식은 계산하지 않습니다.

## 지원 범위

| 형식 | 보기 | 편집·저장 | 제한 |
| --- | --- | --- | --- |
| CSV/TSV | 지원 | 지원 | UTF-8 및 UTF-8/UTF-16 BOM만 쓰기. 최대 10 MiB·10,000행·100,000셀·행당 1,000열. 구분자를 확실히 추정하지 못하면 읽기 전용 오류를 표시합니다. |
| XLSX | 지원 | 제한 지원 | 수식이 없고 검사기가 아는 단순 OOXML 패키지만 저장합니다. 기존에 존재하는 셀만 수정할 수 있습니다. 최대 압축 20 MiB, 512개 항목, 압축 해제 64 MiB·항목당 16 MiB·압축률 200:1·100,000셀입니다. |
| XLSM | 지원되는 OOXML의 값 보기 | 미지원 | 매크로를 실행하지 않고 항상 읽기 전용입니다. |
| DOCX | 본문 텍스트 미리보기 | 미지원 | 문단과 표의 텍스트만 표시합니다. 이미지·레이아웃·주석·변경 내용 표시를 보장하지 않습니다. |
| DOCM | 본문 텍스트 미리보기 | 미지원 | VBA를 실행하지 않으며 항상 읽기 전용입니다. |
| PPTX | 슬라이드 텍스트 미리보기 | 미지원 | 슬라이드 순서와 텍스트 문단만 표시합니다. 배치·도형·이미지·차트·노트는 표시하지 않습니다. |
| PPTM | 슬라이드 텍스트 미리보기 | 미지원 | VBA를 실행하지 않으며 항상 읽기 전용입니다. |
| DOC, PPT | 미지원 | 미지원 | 구형 바이너리 형식입니다. DOCX/PPTX로 변환해야 합니다. |
| XLS, ODS | 미지원 | 미지원 | MVP 범위 밖입니다. |

수식·오류 값·이름 정의·외부 관계·병합·차트·필터·검증 규칙·매크로·서명·미지원 OOXML 구성요소·불명확한 ZIP/XML 구조가 있으면 XLSX 저장을 차단합니다. 읽을 수 있는 경우 값과 수식/캐시값을 표시하며, 캐시값은 오래됐을 수 있습니다. 셀 스타일의 원본 인덱스와 수정하지 않은 패키지 항목을 유지하지만, 날짜·사용자 지정 표시 형식은 해석하지 않고 원시 값을 보여줍니다.

그리드는 viewport 범위만 렌더링하고 최대 60행×30열 범위로 데이터를 요청합니다. 한 문서의 검색, 단일 셀 복사·붙여넣기, 방향키 탐색, Enter/F2 편집을 지원합니다. 다중 셀 범위 복사·붙여넣기, Home/End, 전체 스크린 리더 검토와 대용량 성능 목표 시험은 아직 남아 있습니다. VS Code Web, 원격 파일 시스템과 다중 시트 복사는 지원하지 않습니다.

## 데이터 보존과 보안

- 저장 전 SHA-256 fingerprint를 확인합니다. 저장 중에도 다시 확인하고, 같은 폴더의 임시 파일을 재검증한 뒤 교체합니다. 외부 변경이 감지되면 저장을 중단합니다.
- XLSX는 대상 워크시트 XML의 기존 셀만 바꾸고 ZIP 패키지를 다시 만듭니다. 저장 전후 ZIP CRC, 모든 비수정 항목의 내용 바이트, 재파싱 결과를 확인합니다.
- XLSX ZIP의 항목 수, 압축 후 크기, 압축률, 경로, 로컬·중앙 헤더, 데이터 범위, CRC를 검사합니다. XML은 엄격 모드로 파싱하며 DTD·엔터티·CDATA를 거부합니다. 지원 범위를 넘는 파일은 저장용으로 읽기 전용 처리하거나 안전 검사에서 거부합니다.
- DOCX/DOCM/PPTX/PPTM은 같은 ZIP 크기·경로·CRC 및 XML 안전 검사를 거친 뒤 문단 텍스트만 추출합니다. 매크로, 외부 링크, 임베디드 개체를 실행하지 않습니다. Office 미리보기에는 별도 2 MiB 텍스트 한도가 적용됩니다.
- Webview는 nonce CSP와 타입·범위·입력 길이 검사를 사용합니다. 파일 내용은 네트워크로 보내지 않습니다.
- VS Code의 문서 백업 훅을 사용해 미저장 상태의 hot-exit 백업을 제공합니다. 별도 사용자 복구 UI와 원본 버전 보관 정책은 아직 구현되지 않았습니다.

이 확장은 스프레드시트 데이터를 중요하게 다루므로, 자체 파일을 백업한 뒤 사용하십시오. 알려지지 않은 오류나 파일 기능이 발견되면 저장하지 말고 Excel 등 원본 포맷을 완전히 지원하는 도구로 여십시오.

## 개발과 검증

Node.js 20 이상과 VS Code 1.90 이상을 사용합니다.

```sh
npm ci
npm test
npm run check
npm run test:host
npm run package
```

`npm test`는 CSV 파서, XLSX 보안·round-trip, Office 텍스트 추출·악성 입력 거부, 저장·충돌·백업, Webview 메시지 범위를 검사합니다. `npm run test:host`는 지정하지 않으면 현재 OS용 VS Code Stable을 내려받아 Custom Editor 등록과 CSV·Office 파일 열기를 확인합니다. 로컬 VS Code를 재사용하려면 `VSCODE_EXECUTABLE` 환경변수로 실행 파일 경로를 지정하십시오. GitHub Actions는 Linux·Windows·macOS에서 설치, 테스트, 감사와 VSIX 패키징을 실행합니다.
